# 行测专项 · 判断推理真题化训练（河南）

基于**河南省考（2024、2026）+ 河南事业单位联考（2024）**真题的随机组卷练习工具，资深命题人视角逐错误项拆解干扰设计逻辑。

在线地址：https://951367983.github.io/xingce-zhenti-practice/

## 功能

- **三模块架构**：判断推理（68 题/24 考点）＋ 数量关系（31 题/14 考点）＋ 资料分析（19 题/11 考点）
- **真题来源/年份筛选**：河南省考、河南事业单位联考（2020-2026 年筛选位，2024/2026 河南卷已注入）
- **考点体系**：判断 24 考点（图形位置/样式/属性/数量/立体、定义、类比外延/内涵/语义、逻辑翻译/真假/分析/论证/归纳/解释）＋ 数量 14 考点 ＋ 资料分析 11 考点（倍数/增长率/增长量/基期量/现期比重/基期比重/比重比较/平均数增长率/增长率比较/增长量比较/综合推断）
- **命题人视角解析卡**：每道题 3 个错误选项逐条拆解干扰设计逻辑与典型误区
- **出处核验**：每题标注来源卷别与核验方式（2024/2026 河南省考题干选项依粉笔网友回忆版真题原文，答案经公开真题库与解析卷交叉核对；图表题数据依解析卷重建并注明）
- **答题体验**：计时、不确定标记、交卷判分、考点图谱、分年份统计、错题本与一键重练
