# 行测专项 · 真题化训练（河南）

基于**河南省考（2024、2026）+ 河南事业单位联考（2024）+ 国考/联考真题**的随机组卷练习工具，资深命题人视角逐错误项拆解干扰设计逻辑。

在线地址：https://951367983.github.io/xingce-zhenti-practice/

## 功能

- **四模块架构**：判断推理（68 题/24 考点）＋ 数量关系（31 题/14 考点）＋ 资料分析（98 题/31 考点）＋ 言语理解（90 题/26 考点）
- **真题来源/年份筛选**：河南省考、河南事业单位联考、国考/联考真题三类来源（2016-2026 年份筛选）
- **资料分析考点全覆盖（31 考点）**：现期量、基期量、增长量、增长量比较、增长率、增长率比较、百分点、隔年增长率、年均增长率、年均增长量、混合增长率、拉动增长与贡献率、现期比重、基期比重、两期比重、比重变化判断、现期平均数、基期平均数、平均数增长率、平均数增长量、现期倍数、基期倍数、基期量和差、和差计算、读数与排序比较、倍数与比值、增长率计算、增长量计算、基期量计算、比重比较、综合推断（推出几项）
- **言语理解 26 考点**：语境对应（关键词定位/中心话题/解释说明）、逻辑关联（反义/并列/递进/因果/条件）、多对一全匹配验证、成语辨析（本义/拆分/感情色彩/语义轻重）、实词辨析（语义侧重/搭配对象/程度范围）、选项呼应自洽性、主体视角角色对应、目的/结果/措施区分、比喻/修辞对应、高频复现词统计、语句衔接承上启下、常识/背景对应、标点/符号提示、语句排序首句与捆绑、细节判断六类偷换
- **命题人视角解析卡**：每道题 3 个错误选项逐条拆解干扰设计逻辑与典型误区
- **出处核验**：每题标注来源卷别与核验方式；国考/联考真题化训练题数据经校订自洽、可独立验算，答案由题库原始解析逐题核对
- **答题体验**：计时、不确定标记、交卷判分、考点图谱、分年份统计、错题本与一键重练
